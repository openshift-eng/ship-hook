# SHIP Hook Specifications

This directory holds lightweight design specs for significant features. Specs are Markdown files intended to be useful to both humans and coding agents.

Specs describe intent, abstract concepts, responsibilities, and behavioral
contracts. Include concrete syntax only when it defines behavior users depend
on. Keep deployment values, code walkthroughs, data structures, and mechanical
wiring in code or operational documentation. Each spec owns one concern and
links to shared concepts rather than restating their implementation.

## Template

```markdown
# Title

## Status
Draft | Accepted | Implemented

## Motivation
Why this change is needed.

## Design
The concepts, responsibilities, behavioral contracts, and relevant tradeoffs.

## Verification
How to verify the change works correctly.
```
